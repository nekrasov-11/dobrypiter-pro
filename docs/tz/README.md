## Общие правила для всех страниц

- Прод живой: форму заявок (Cloudflare Worker) и Метрику не ломать; проверять на review-окружении.
- Страницы кладутся в `web/<slug>/index.html`; пути к общим ресурсам — **корневые абсолютные** (`/style.css`, `/script.js`, `/assets/...`), как требует [00-arhitektura-stranic.md](00-arhitektura-stranic.md) §2 — оно главнее при расхождениях.
- Каждая страница: canonical, OG, JSON-LD (Service+Offer, FAQPage), запись в `web/sitemap.xml` с lastmod.
- Организация в schema — только ссылкой `{"@id": "https://dobrypiter.pro/#org"}` (полное описание живёт на главной).
- Тексты пишет content-editor по своему промпту; тон: дружелюбный, но уверенный, для людей. Ключи без переспама (1–2 вхождения на секцию).
- После выката: отправить новые URL на переобход в Яндекс.Вебмастере, обновить ссылки на страницы в Яндекс.Бизнесе (услуги с ценами).

При смене статуса — править колонку «Статус» в таблице (☐ не начато / ◐ в работе / ☑ готово / 🚀 на проде).

## Уроки пилота (04.08.2026) — учесть при вёрстке остальных 4 страниц

Шаблон обкатан на `/tseny/`, копировать разметку оттуда (не с главной — там относительные пути).

1. **Проверять баланс тегов парсером перед коммитом.** В пилоте потерялись два `</div>`
   (`.coach-badges` и `.contact-grid`) — браузеры чинят это сами, поэтому ни визуальный QA,
   ни чистая консоль ошибку не показали. Поймал только code-review. Ошибка размножилась бы ×5.
2. **`.hero-right` на мобилке.** Базовый класс сочетает `min-height: 240px` с `aspect-ratio: 16/9`
   и получает ширину 427px при экране 360px — края уходят под `overflow: hidden`. Для фото
   использовать `.hero-right hero-right--photo` (модификатор уже в секции Subpages).
3. **Заголовки карточек — с ключами** («Бокс для детей и подростков», а не «Детская группа»).
4. **Точные имена групп для `data-schedule-groups`** (сверено с API 04.08.2026):
   `Детская группа`, `Подростковая группа`, `Взрослая группа`, `Женская группа`, `Индивидуальные`.
   Внимание: в ТЗ-00 §5.2 указано «Индивидуально» — в API на самом деле «Индивидуальные».
5. **Фолбэк расписания верстать через `<div class="sch-card-title">`, а не `<h3>`** —
   `renderSchedule` (`web/script.js:37`) отрисовывает div, иначе после ответа API уровень
   заголовка поменяется на лету.
6. **Ссылки на соседние страницы ставить только на существующие.** Перелинковка между
   группами и футерный блок `.foot-links--pages` — Этап 4, когда все страницы будут на проде.
7. Общие правки кода этапа 1 **уже сделаны**: фильтр расписания и `page` в payload
   (`web/script.js`), поле `page` в Telegram-сообщении (`worker/worker.js`, Worker задеплоен
   04.08.2026), версия ассетов `?v=20260804a` во всех HTML.
