## 3. Структура страницы

1. **H1 + лид** (400–600 знаков). Вхождения: «бокс для взрослых», «Калининский район», «метро Лесная», «тренировки по боксу». Суть: вечерняя группа после работы, берём с любого уровня — от «никогда не стоял в стойке» до подготовки к турнирам.
2. **H2 «Кому подойдёт»** (700–1000 знаков): новичкам с нуля (никто не бросит в спарринг); тем, кто хочет форму вместо скучного фитнеса; бывшим спортсменам, возвращающимся после перерыва; любителям с амбициями — соревнования. Снять барьер возраста: начать можно и в 30, и в 40+ (отзыв Владимира, 58 лет — цитата). Вхождение: «бокс для начинающих взрослых».
3. **H2 «Что даёт бокс взрослому»** (600–900 знаков, карточки): выносливость и сила, снятие стресса после работы, уверенность, дисциплина и режим. Вхождение: «заниматься боксом».
4. **H2 «Как проходит тренировка»** (800–1000 знаков): 90 минут — разминка, школа бокса (техника ударов, защита, передвижения), снаряды и лапы, работа в парах по готовности, ОФП. Отдельно: для выступающих — индивидуальный план, секундирование на турнирах (фото `../assets/1.jpg`, `../assets/4.jpg`).
5. **H2 «Тренер»** (500–700 знаков + фото `../assets/trener.jpg`): регалии из раздела 0; фишка из отзывов — консультации по питанию и домашним занятиям (цитата Дениса). Вхождение: «тренер по боксу».
6. **H2 «Расписание взрослой группы»** — Пн/Ср/Пт 20:30–22:00 (данные с главной, не менять).
7. **H2 «Цены»** — таблица:
   | Абонемент 8 тренировок (2 р/нед) | 5000 ₽ |
   | Абонемент 12 тренировок | 6000 ₽ |
   | Разовая тренировка | 1000 ₽ |
   | Пробная тренировка | 500 ₽ |
   ⚠️ Вопрос владельцу (не блокер): группа занимается 3 р/нед, абонемент «2 р/нед» на 8 занятий — уточнить корректную формулировку, не выдумывать.
   Ссылка «Полный прайс клуба» → `/tseny/`.
8. **H2 «Частые вопросы» (FAQ, 4–5 вопросов)** — примеры:
   - Я никогда не занимался — возьмёте? (да, техника ставится с нуля)
   - Обязательны ли спарринги? (нет, только по готовности и желанию)
   - Что взять на первую тренировку? (форма, кроссовки, вода; перчатки — **уточнить у владельца**)
   - Можно ли подготовиться к соревнованиям? (да — воспитанники выступают на турнирах вплоть до Первенства России)
   - Есть ли утренние тренировки? (в группе — вечер; утром — индивидуально, ссылка на `/individualnye-trenirovki/`)
9. **CTA-блок с формой** — предвыбрать группу `Взрослая`.
