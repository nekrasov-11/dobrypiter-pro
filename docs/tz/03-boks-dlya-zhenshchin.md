## 3. Структура страницы

1. **H1 + лид** (400–600 знаков). Вхождения: «бокс для женщин», «Санкт-Петербург», «метро Лесная». Суть: отдельная женская группа, утреннее время, никакого «мужского зала на минималках» — полноценный бокс в комфортном темпе.
2. **H2 «Зачем женщине бокс»** (800–1200 знаков, карточки выгод): форма и похудение (бокс — интенсивное кардио), разгрузка головы и стресс, уверенность и базовая самооборона, осанка и координация. Снять главный барьер: «не будет ли меня бить» — спарринги не обязательны, работа на снарядах и лапах. Вхождения: «женский бокс», «бокс для похудения» (естественно, без обещаний конкретных килограммов).
3. **H2 «Для кого группа»** (500–800 знаков): с нуля и без спортивного прошлого; любой возраст (в отзывах — участницы разных возрастов); удобно мамам — утренние слоты. Вхождение: «бокс для начинающих девушек».
4. **H2 «Как проходит тренировка»** (700–1000 знаков): разминка, техника (стойка, передвижения, удары), снаряды/лапы, ОФП и растяжка. Длительность 60 минут. Атмосфера группы — поддержка, без сравнений и муштры.
5. **H2 «Тренер»** (400–600 знаков + фото `../assets/trener.jpg`): регалии, акцент на умении работать с новичками; вставить 1–2 отзыва женщин (из раздела 0) как цитаты.
6. **H2 «Расписание женской группы»** — Вт/Чт 09:30–10:30, Сб 11:00–12:00 (данные с главной, не менять).
7. **H2 «Цены»** — таблица:
   | Абонемент 8 занятий | 5000 ₽ |
   | Абонемент 12 тренировок | 6000 ₽ |
   | Разовая тренировка | 1000 ₽ |
   | Пробная тренировка | 500 ₽ |
   Ссылка «Полный прайс клуба» → `/tseny/`.
8. **H2 «Частые вопросы» (FAQ, 4–5 вопросов)** — примеры:
   - Я никогда не занималась спортом — получится? (да, группа рассчитана на новичков)
   - Обязательно ли драться/спарринговать? (нет, только по желанию и готовности)
   - Что взять на первое занятие? (форма, кроссовки, вода; перчатки — **уточнить у владельца, выдаёт ли клуб**)
   - Есть ли вечернее время для женщин? (женская группа утром; вечером можно во взрослую группу или индивидуально — со ссылками)
   - Поможет ли бокс похудеть? (интенсивное кардио + режим; честно, без гарантий)
9. **CTA-блок с формой** — предвыбрать в `select` группу `Женская`.
