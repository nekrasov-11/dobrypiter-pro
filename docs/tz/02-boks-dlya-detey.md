## 3. Структура страницы

1. **H1 + лид** (400–600 знаков). Вхождения: «бокс для детей», «Санкт-Петербург», «Калининский район», «метро Лесная». Суть: две группы по возрасту, дисциплина и уверенность, первый шаг — бесплатное пробное.
2. **H2 «Что даёт бокс ребёнку»** (800–1200 знаков, можно карточками). Выгоды для родителя (решение принимает родитель!): дисциплина, уверенность, умение постоять за себя, физическая форма, выход энергии, характер. Без агрессивной риторики — родители боятся травм, снять страх: контролируемые нагрузки, спарринги только с готовностью и защитой. Вхождение: «детская секция бокса».
3. **H2 «Группы по возрасту»** (600–900 знаков): детская **6–13 лет** и подростковая **14–17 лет** (подтверждено владельцем 03.08.2026), чем отличаются программы (игровая подача vs полноценная техника и подготовка к соревнованиям). Вхождение: «бокс для подростков».
4. **H2 «Как проходит тренировка»** (800–1000 знаков): разминка, ОФП, школа бокса (стойка, передвижения, удары), работа на снарядах и лапах, игровые элементы у младших. Длительность 75 минут.
5. **H2 «Тренер»** (500–700 знаков + фото `../assets/trener.jpg`): регалии из раздела 0, акцент на детском опыте — воспитанники с медалями турниров (фото `../assets/3.jpg`, `../assets/6.jpg` с alt про детей). Вхождение: «тренер по боксу для детей».
6. **H2 «Расписание детских групп»** — карточки расписания из раздела 0 (скопировать данные, не менять).
7. **H2 «Цены»** — таблица:
   | Абонемент 12 тренировок | 5000 ₽ |
   | Разовая тренировка | 500 ₽ |
   | Пробная тренировка | бесплатно |
   Цифры подтверждены владельцем 03.08.2026.
   Ссылка «Полный прайс клуба» → `/tseny/`.
8. **H2 «Вопросы родителей» (FAQ, 5 вопросов)** — примеры:
   - Со скольки лет берёте в секцию? (с 6 лет: детская группа 6–13, подростковая 14–17)
   - Берёте ли девочек? (да)
   - Что нужно на первое занятие? (форма, обувь; перчатки на первое занятие выдаёт клуб — подтверждено владельцем)
   - Это не опасно для ребёнка? (контролируемые нагрузки, спарринги только по готовности)
   - Как записаться на бесплатное пробное? (форма ниже / телефон)
9. **CTA-блок с формой** — в `select name="group"` предвыбрать `Детская` (option selected), родитель сможет сменить на «Подростковая».

## 4. Объём и тон

- Объём: **5000–8000 знаков**.
- Tone of voice: дружелюбный, но уверенный. Адресат — родитель, а не ребёнок. Без запугивания и без обещаний «чемпионства за месяц». Ключи — естественно, 1–2 вхождения на секцию.
