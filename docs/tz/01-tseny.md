## 4. Объём и тон

- Объём: **3000–5000 знаков** без учёта таблиц. Страница прежде всего коммерческая: таблицы важнее «простыней» текста.
- Tone of voice: дружелюбный, но уверенный; для людей, не для робота. Без канцелярита и переспама — каждый ключ максимум 1–2 естественных вхождения.

## 5. Schema.org

В `<head>` JSON-LD:

1. **Привязка к организации:** организация уже описана на главной как `SportsActivityLocation` с `@id: "https://dobrypiter.pro/#org"` — ссылаться на неё через `"provider": {"@id": "https://dobrypiter.pro/#org"}`, не дублировать полный блок.
2. **Service + OfferCatalog** (пример каркаса, цены — из таблиц выше):

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "Тренировки по боксу",
  "serviceType": "Секция бокса",
  "areaServed": {"@type": "City", "name": "Санкт-Петербург"},
  "provider": {"@id": "https://dobrypiter.pro/#org"},
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "Цены на тренировки по боксу",
    "itemListElement": [
      {"@type": "Offer", "name": "Абонемент, взрослая группа, 8 тренировок", "price": "5000", "priceCurrency": "RUB"},
      {"@type": "Offer", "name": "Разовая тренировка, взрослая группа", "price": "1000", "priceCurrency": "RUB"}
    ]
  }
}
```
Перечислить в `itemListElement` ВСЕ позиции прайса (детские, женские, взрослые, индивидуальные).
3. **FAQPage** — все вопросы из секции FAQ (mainEntity → Question/acceptedAnswer). FAQ в schema должен дословно совпадать с видимым текстом.
